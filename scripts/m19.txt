二、Kimi K3.1 Pro 置顶

新增 `leads_the_issue(title)`：**命名模型 + 版本号 + 发布动词** 三条同时成立就置顶。

  _MODEL_FAMILY = kimi|deepseek|claude|gpt|gemini|qwen|llama|glm|grok|mistral|sora
  _VERSION      = V4 / K3.1 / 5.5 / Pro
  _RELEASE_VERBS= 发布|上线|推出|开源|正式可用|release|launch …

为什么不用一条正则：`DeepSeek 发布 V4` 中间隔着「发布」，
单个正则看不到这两段相邻。改成两次独立判断。

排序时置顶项排在最前，其余仍按栏目 + 分数：

  chosen.sort(key=lambda r: (
      0 if leads_the_issue(r.event.title) else 1,
      rank_of(section),
      -r.score,
  ))
