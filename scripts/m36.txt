二、根因

`published_history.jsonl` 里同一天有 4 条记录：

  10-24 history:  36 events   ← 第 1 轮
  10-24 history:  88 events   ← 第 2 轮
  10-24 history:  98 events   ← 第 3 轮
  10-24 history: 108 events   ← 第 4 轮

`record()` 用 `open('a')` **纯追加**，同一天每跑一次就多一行。

于是第 N 轮把第 N-1 轮的产出当成「7 天内已发布过」。

**我一直在重跑验证，而每次重跑都在给下一次埋雷。**

════════════════════════════════════════════════════════════════════════
三、修法

写入前先删掉同日期的旧行：

  existing = [row for row in 文件 if row['date'] != date]
  写回 existing + 新记录

重跑一个日期 = **替换**该日期的记录，不是追加。
文件永远描述每个日期最后一次发布的版本。

同时清理了现有的脏数据：

  27 条记录 → 11 条（删掉 16 条同日重复）
