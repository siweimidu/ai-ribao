fix(dedup): 合并后没更新证据等级，事实校验拦下整期（exit 2）

════════════════════════════════════════════════════════════════════════
一、这次的失败

  40092972554   publish 失败三次
    publish failed with exit code 2 after 3 attempts

`exit 2` 不是崩溃，是**事实校验主动拒绝发布**：

  事实校验：剔除 1 条问题事件
  {ok: false, checked_events: 260, violations: 1,
   by_kind: {wrong_evidence_level: 1}}
  !! 事实校验未通过，不发布

════════════════════════════════════════════════════════════════════════
二、是我的 LLM 去重造成的

事实校验的规则：

  if event.evidence_level == 'single_source' and event.independent_source_count > 1:
      → wrong_evidence_level

**合并正是这样发生的**：我 union 了 source_ids、重算了 independent_source_count，
**但没有更新 evidence_level** —— 来源变成 2 个，标签还写着「单源」。

════════════════════════════════════════════════════════════════════════
三、修法

合并后按 union 后的来源数重算等级：

  if target.independent_source_count >= 2:
      target.evidence_level = 'multi_source'
  else:
      target.evidence_level = 'single_source'

用重算而不是递增，所以合并的合并也正确。

════════════════════════════════════════════════════════════════════════
四、这次是保护机制在起作用

事实校验拦住了一次「声称多源但证据不足」的发布 —— 这正是它该做的。

但它拦的方式是**整期不发布**，代价太大。两个问题分开看：

  · 我的 bug（证据等级没同步）—— 已修
  · 校验失败导致整期作废 —— 设计如此，因为发布一条假的多源验证比不发更糟
