一、数据从哪来

artificialanalysis.ai 是 Next.js 应用，数据以 `self.__next_f.push([1, "..."])` 流式下发。
榜单页的 payload 里有一个 `initialModels` 数组，装着全部 272 个模型。

实测 2026-10-23：

  1.9 MB HTML → 657 KB flight payload → 272 个模型

**没有分页，没有 API key，一次请求。**

为什么不用渲染后的 HTML：表格行是虚拟化的，可见文本只有首屏；payload 才是页面自己
用的同一份数据。

二、保留了什么

排名要能解释自己，所以除了智能指数还带：

  价格（输入/输出，每百万 token）
  上下文窗口
  是否推理模型、是否开源权重、分数是否为估算
  构成指数的各项基准（tau2 / gpqa / hle / ifbench / lcr …）

**站点给 null 的字段保持 null，不变成 0** ——「没测」和「得 0 分」是两件事。
