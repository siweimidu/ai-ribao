一、你问的「我不是给你 API 了嘛，为什么还要凭证」

这是真 bug，不是配置问题。

`select_sources` 原来这样判断：

    elif spec.needs_credential:
        skipped.append((spec.source_id, f"needs credential: {spec.needs_credential}"))

**只要有 `needs_credential` 字段就跳过，根本不看环境变量里有没有这个 key。**

所以你把 TAVILY_API_KEY 配好了，它照样报「待凭证」，而且从代码外部没法修。

改成：

    elif spec.needs_credential and not os.environ.get(spec.needs_credential, "").strip():

`needs_credential` 现在的意思是「这个源需要名为 NAME 的变量」，不是「这个变量缺了」。

验证：

  无 TAVILY_API_KEY  → 可采集 0，跳过 1（needs credential: TAVILY_API_KEY）
  有 TAVILY_API_KEY  → 可采集 1，跳过 0

二、Tavily 的适配器也指错了

registry 里写的是 `adapter: ApiFetcher` —— 那是生成器给所有 source_type=api 的源
批量写的占位名。而 Tavily 是 POST 检索接口，没有可 GET 的 URL，通用 JSON 读取器
对它发 GET 必然失败。

`TavilyFetcher` 早就实现了（src/aidaily/fetchers/tavily.py），只是没人接上。
已在 overrides 里改为 TavilyFetcher 并启用。
