# 栏目判定（section.md）

**这个文件决定日报的呈现顺序，它比分数更重要。**

## 为什么

对 `daily.juya.uk` 十期的编号做了反向分析：每条新闻都带序号（`... ↗ #17`），
而序号是**按栏目连续分配的**：

```
2026-10-15  要闻 #1-2 | 模型发布 #3-6 | 开发生态 #7-10 |
            产品应用 #11-13 | 技术与洞察 #14-17 | 行业动态 #18-27
```

两两先后统计里 **13 组从未反转**，只有 `开发生态` 与 `模型发布` 是 5:4。
也就是说**排序的第一主键是栏目，不是分数**。

而且栏目**内部**的顺序无法用标题特征复原：位置与标题长度、是否含大厂名、是否含发布动词
等特征的 Spearman 相关全部低于 0.35，且符号在各栏目之间翻转（`含数字` 在模型发布里是
+0.34，在开发生态里是 -0.24）。那部分是编辑判断。

**结论：把栏目判对，就等于把粗排序做对了。** 一条被排在 47 位而橘鸦放在要闻的新闻，
靠调权重永远救不回来 —— 差别是分类的，不是连续的。

## 优先级（从上述统计直接得出）

```
要闻  >  开发生态  >  模型发布  >  产品应用  >  技术与洞察  >  行业动态  >  其他
```

排序时**先按栏目，再按分数**。

## 六个栏目的判据

每一条边界都取自橘鸦真实出现过的情况，不是凭空定义。

### 要闻 —— 美国前沿实验室改变了读者今天必须知道的东西

**只有** OpenAI / Anthropic / Google / Meta / Microsoft / xAI。

实测：橘鸦十期里 40 条要闻**全部**来自这几家。`豆包工作上线数据导入`、
`千问推出个人 Agent` 是产品应用，不是要闻。

包含的不只是模型：`Claude Code 桌面版更新`、`OpenAI 优化 ChatGPT 桌面应用存储占用`、
`Codex 第 8 天安排`、`Claude Sonnet 5.5 缓存读取价格减半` 都在这里。

### 开发生态 —— 面向开发者的获取方式、工具与价格

`OpenCode Go 上线 Gemini 4 Argon`、`Qoder 国际版极致档位推出夜间 2 折优惠`、
`OpenAI 公布部分 GPT-4 模型退役安排`、`Claude Platform 支持导出 OpenTelemetry 追踪`、
`Command Code 推出 GOAT 限时额度优惠`、`Cursor 的 Origin 支持逾 20 项集成`。

**额度、折扣、订阅、限免、退役、API/SDK 变化都属于这里**，不属于行业动态。

### 模型发布 —— 发布的是一个模型

`蚂蚁百灵开源 Ling-3.1-flash 模型`、`智谱推出法律模型 GLM-Legal`、
`Fish Audio 发布 Drama 3，开放模型权重`、`Liquid AI 发布 LFM2.5-24B-A2B`、
`腾讯优图开源多模态解析模型 Youtu-Parsing-Omni`。

判据是**被发布的对象是不是模型**。`豆包工作上线数据导入功能` 发布的是应用，不是模型。

### 产品应用 —— 发布的是产品或应用，消费级或企业级

`豆包工作上线数据导入与同步功能`、`企业微信接入 WorkBuddy，侧边栏可领用`、
`llama.cpp 推出 Windows 桌面应用 Llama Windows`、`千问开售 N 系列 AI 眼镜及耳夹式耳机`、
`Grok Bot 推出用户专属邮箱`、`Google Play 新增私人应用功能`。

### 技术与洞察 —— 研究、评测、报告、方法论

`AA-Robotics 评测：GPT-6 Astra 居首`、`Swarmchasers 报告腾讯云 Agent 试绕高德反爬`、
`Anthropic 弃用 Git，自建版本控制系统 Scion`、`AA 新增缓存命中率与任务成本对比榜单`、
`AISI 发布开源评估工具 Transect`。

**注意**：`Anthropic 弃用 Git，自建 Scion` 含有"弃用"这个开发词，
但它的价值是**工程决策的洞察**，所以在这里而不在开发生态。
判据是「这条内容让人学到什么」，不是它出现了哪个词。

### 行业动态 —— 钱、法、组织

营收、融资、估值、收购、诉讼、监管、份额、人事、资助。
`报道称 Anthropic 第三季度营收达 168 亿美元`、`OpenAI 基础设施负责人将离职`、
`谷歌向 17 家机构提供 3600 万美元 AI 科研资助`、`苹果多款国行 iPhone 新增大模型备案编号`。

### 其他 —— 判不出来的时候

宁可放这里，也不靠猜把它提上去。其他排最后。

## 容易混的三组

| 混淆 | 判据 |
|---|---|
| 模型发布 vs 产品应用 | **被发布的对象**是模型还是应用 |
| 开发生态 vs 模型发布 | 是**模型本身**，还是**获取它的方式**（额度、折扣、退役、API） |
| 要闻 vs 产品应用 | 是不是**美国前沿实验室**的产品变化 |

## 输出

每条给一个栏目名，只能是上面七个之一。同时给 3-5 个具体话题标签
（例如「模型发布」「开源权重」「算力」「监管」），
不要用「AI」「技术」这种所有条目都适用的标签。
