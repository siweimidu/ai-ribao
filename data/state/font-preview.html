四、取舍：请注意三件事

项目说明
体积四个字族的 CSS 请求约 1.0 MB（936 个 @font-face，按需分片下载）。 整站字体从 0 变成需要联网下载。
离线 / 断网Google Fonts 在国内通常可达（实测 HTTP 200），但被墙时页面会退回到 系统字体 —— 不会乱码，只是变回现在的样子。
可读性宋体在大字号标题上气质最好；正文仍建议用无衬线（右栏那样）， 因为宋体小字在屏幕上笔画细、阅读慢。这也是模板自己的做法。

如果你要「全部改成宋体」，我就把正文也换成 serif；如果想更稳妥，就按模板的做法： 标题与封面用 serif，正文用 sans，数字与时间用 mono。你定。
