    Nvidia 研究者认为超大 Context Window 是死路

    单一来源 11-22 00:23 the-decoder.com

    事实

    • Nvidia 研究团队表示模型 Context Window 的持续扩大是过度且昂贵的做法
    • GPT-4 于 2023 年 3 月发布时 Context Window 为 8,192 tokens
    • GPT 5.6 Sol 可处理约 100 万 tokens，容量约为 GPT-4 的 120 倍
    • 在多项测试中，定期摘要加定向检索的效果与使用全量 Context Window 相当
    • Nvidia 团队提出了一种新的模型类别，该模型使用短笔记代替长 Context Window

    推断

    • 由于全量 Context Window 成本高昂且易出错，Nvidia 团队提出的基于短笔记的新模型类别可能在成本效益上优于传统长 Context Window 方案
    • GPT 5.6 Sol 相比 GPT-4 在 Context Window 上的巨大增幅（120 倍）并未解决全量 Context Window 慢、贵、易出错的问题

    不确定

    • 材料中未提供“多项测试”的具体测试名称或详细数据
    • 材料中未明确 GPT 5.6 Sol 的发布时间和所属公司
    • 材料中未说明 Nvidia 团队提出的新模型类别的具体名称或架构细节
