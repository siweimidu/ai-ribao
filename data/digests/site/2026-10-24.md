*2026-10-24 19:12　来源 2 个　单一来源*

**事实**
- Anthropic 的 sandbox-runtime (srt) 是一个开源的操作系统级沙箱
- sandbox-runtime 是 Claude Code 背后的沙箱机制
- 在 macOS 上使用 Seatbelt 机制限制 agent、MCP 服务器和 CLI 工具的文件与网络访问
- 在 Linux 上使用 bubblewrap 机制限制 agent、MCP 服务器和 CLI 工具的文件与网络访问
- 该方案不需要容器即可实现隔离
- npm 包 @anthropic-ai/sandbox-runtime 的当前版本为 v0.0.81
- 该项目采用 Apache-2.0 协议

**推断**
- 使用原生 OS 隔离机制（Seatbelt 和 bubblewrap）可能比容器方案提供更轻量的隔离开销
- 该工具支持限制任意进程的文件与网络访问，表明其具有通用的进程沙箱能力
