### AWS Agent Registry支持运行时发现工具
*2026-10-21 00:22　来源 1 个　单一来源*

**事实**
- 代理的工具目录从少量工具扩展到数百个工具时，硬编码工具连接会失效。
- 方案基于 AWS Agent Registry 构建运行时发现、实例化和执行循环。
- 编排器通过语义搜索在运行时发现 MCP 服务器和 A2A 代理，而不是在构建时编译每个工具。

**推断**
- 该方案可能减少工具数量增长后对预先配置工具连接的依赖。

**不确定**
- 材料没有说明 AWS Agent Registry 支持的具体工具数量。
- 材料没有说明语义搜索使用的具体方法和评估结果。
- 材料没有说明运行时发现、实例化和执行循环的具体实现细节。
